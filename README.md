# Point After Pub & Grille Astro Redesign

## Stack
- Astro
- Tailwind CSS
- Cloudflare Pages compatible

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Cloudflare Pages
Build command:
```bash
npm run build
```
Output directory:
```bash
dist
```

## Replace placeholders
- `public/favicon.svg`
- Header logo circle in `src/components/Header.astro`
- Placeholder image blocks using the `placeholder-img` utility class
- `/menu.pdf` with the real current menu PDF
